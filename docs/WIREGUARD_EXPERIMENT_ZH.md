# WireGuard 网卡房间实验说明

07、08 房间使用独立的 `wireguard` 连接模式。进入房间时只准备一个临时 WireGuard/Wintun 适配器，并向服务器登记本机临时公钥；不为房间内所有成员创建通道。Hook 仍负责 WE8 搜索广播，收到真实 `GAME_PEER` 事件后才为这一个对手下发和配置 peer。

服务端控制器只登记进入 07/08 的客户端公钥和虚拟地址。比赛配对后，双方各自发布已由服务器观察到的公网端点；客户端只取得本场对手的公钥、端点和 `/32` 路由。端点尚未被服务器观察到时，客户端会有限重试，随后回退现有 Hook + 云中继。路径状态只在连接、失败或断开时改变，不对游戏数据面做轮询。

客户端安装包现在随附官方签名的 WireGuard MSI。进入 07/08 房间时会先检查本机已有的 WireGuard；未安装时自动请求管理员权限安装 Wintun、WireGuard 工具和隧道服务，安装失败则保留现有云中继回退。正式对外开放前仍需要：

1. 按服务端仓库 `platform/deploy/wireguard/README.md` 配置 `welwg0` 的 `10.222.7.1/24, 10.222.8.1/24` 地址、控制器与 `51820/UDP`。
2. 使用两名真实异地玩家测试直连、失败回退、比赛结束后的下一场复用和退出房间后的适配器清理。

首次进入网卡房间创建临时隧道、退出时卸载隧道服务，Windows 可能要求一次管理员授权；客户端会先尝试普通权限，只有系统返回提权错误时才弹出 UAC。直连/中继房间不经过这条 WireGuard 服务流程。

比赛结束仅移除本场对手 peer，适配器和服务器汇合 peer 保留给下一场；退出房间才卸载临时隧道并删除服务端客户端登记。
